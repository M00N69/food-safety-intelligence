# Food Safety Intelligence — Portail

Portail de découverte et de qualification des **sources officielles en sécurité des aliments** (Union européenne et France).

## Contenu

- **50 ressources officielles** dans 15 domaines de connaissances — URLs vérifiées le 21/11/2026
- **Parcours par situation** : 4 situations courantes, chacune ouvre un chemin de 4 étapes avec les sources à ouvrir dans l'ordre
- **Catalogue filtrable** : type d'accès, périmètre géographique, caractéristiques (liens vérifiés, API), tri
- **Visite guidée** de 5 étapes
- **Favoris** enregistrés localement dans le navigateur (aucune donnée envoyée)

## Utilisation

Ouvrir `food_safety_intelligence_landing_page.html` dans un navigateur — **aucune connexion ni serveur requis**, le fichier est totalement autonome (aucune dépendance externe, aucune police ni librairie distante).

## Édition

Le catalogue est décrit dans le tableau `resources[]` en début de `<script>` : ajouter une source = ajouter une entrée (domaine, organisme, statut juridique, type d'accès, URL, date de vérification).

## Avertissement

Ce portail est un outil de découverte. Ce n'est **pas un site officiel de l'Union européenne** : vérifiez toujours la version du texte en vigueur avant toute décision.
